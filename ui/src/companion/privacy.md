# Privacy Statement

**Euro-Hub. Version 1, effective 18 November 2026.**

## 1. Introduction

This Privacy Statement describes how Euro-Hub processes personal data. Euro-Hub is the add-on for Euro Truck Simulator 2 and American Truck Simulator made by MOF Technologies: the app for Windows with its companion window, the plugin that runs in the game, the truck screen in the cab and the optional iPad screen (together: "**the Software**").

It is issued in accordance with Regulation (EU) 2016/679, the General Data Protection Regulation (**GDPR**). The English version of this Privacy Statement is the binding version.

## 2. Controller

Euro-Hub itself has no servers and keeps no personal data of its users. For the optional Omsi-Hub account (section 4), the controller is Omsi-Hub, the sister product of Euro-Hub, and Omsi-Hub's own Privacy Statement at https://omsihub.com applies in addition to this one.

Questions about this Privacy Statement may be sent to **info@omsihub.com**.

## 3. Use of the Software without an account

Euro-Hub can be used in full without an account. Everything it keeps — settings, maps, the tachograph's records, the coach company, wallpapers and logs — stays on the user's own computer. Euro-Hub does not collect or send analytics. The following network communication nevertheless occurs:

- **Updates.** Euro-Hub looks for new versions on GitHub, Inc. and downloads them from it. GitHub processes the user's IP address in this context.
- **Music, video and Discord.** The user signs in to Apple Music, Spotify, YouTube and Discord on those services' own pages, in Euro-Hub's own browser profile on the user's computer, as in a web browser. Euro-Hub keeps no account data of its own for them; each service processes data under its own privacy policy.
- **Support.** The Kreosus page opens only when the user chooses "Support me".
- **iPad.** The optional iPad screen connects to Euro-Hub over the user's local network only.

## 4. The optional Omsi-Hub account

A user may sign in to Euro-Hub with an Omsi-Hub account, the same account used in Omsi-Hub and on omsihub.com. Signing in is optional and is used only to show the user's profile in Euro-Hub. An account is created on omsihub.com, not in Euro-Hub.

When the user signs in, Euro-Hub processes the following personal data:

- **Email address and password**, when the user signs in with them. They are sent directly and encrypted to Omsi-Hub's account service, Supabase (Frankfurt, Germany). Euro-Hub does not store the password.
- **Sign-in with Google or Discord**, when the user chooses it. The sign-in takes place in the user's own web browser on the page of Google LLC or Discord Inc.; the provider passes the user's identifier and email address (and, for Discord, the username and the address of the profile picture) to Omsi-Hub's account service, as described in Omsi-Hub's Privacy Statement. The browser returns to Euro-Hub through a one-time listener on the user's own computer (127.0.0.1) that closes after the sign-in.
- **The profile**: the display name, friend code, email address and profile photo of the account, read from Omsi-Hub's account service to be shown in Euro-Hub. If the account has no profile yet, Euro-Hub creates it with the name chosen on omsihub.com, as Omsi-Hub's own app does.
- **The session**: a sign-in token is kept on the user's computer, in the companion window's storage, so that the user stays signed in. Signing out in Euro-Hub deletes it.
- **Consent**: the version of this Privacy Statement the user accepted is kept on the user's computer.

The legal basis is the performance of a contract (Art. 6(1)(b) GDPR) for the sign-in and the profile, and the user's consent (Art. 6(1)(a) GDPR), given before the first sign-in, for using the account in Euro-Hub. Euro-Hub does not use personal data for automated decision-making or profiling, does not sell it and does not display advertising.

## 5. Recipients

- **Supabase, Inc.**, Omsi-Hub's processor, hosts the accounts and profiles (Frankfurt, Germany, European Union).
- **Google LLC** and **Discord Inc.** are independent controllers, only when the user chooses to sign in with them (United States).
- **GitHub, Inc.** is an independent controller for update checks and downloads (United States).

Where personal data is transferred outside the European Economic Area, this takes place on the basis of an adequacy decision of the European Commission, including the EU–U.S. Data Privacy Framework, or the Standard Contractual Clauses.

## 6. Retention

- The sign-in token is kept until the user signs out in Euro-Hub, or until it is refused by Omsi-Hub's account service.
- The account and profile are kept by Omsi-Hub for as long as the account exists, as described in Omsi-Hub's Privacy Statement. The user may delete the account at any time on omsihub.com.
## 7. Security

All communication with Omsi-Hub's account service, Google and Discord is encrypted (HTTPS). The listener for the browser's return answers only on the user's own computer, only to the sign-in it started, and stops after the first answer or five minutes. Access to account data is restricted by Omsi-Hub's row-level security, so that each account can read only its own data.

## 8. Your rights

Under the GDPR the user has the right of access, rectification, erasure, restriction of processing, data portability and objection, and may withdraw consent at any time by signing out; withdrawal does not affect processing before it. Most of these rights can be exercised on omsihub.com (My Omsi-Hub), or by writing to info@omsihub.com. The user may also lodge a complaint with a supervisory authority, in the Netherlands the Autoriteit Persoonsgegevens.

## 9. Changes

When this Privacy Statement changes, its version number changes, and Euro-Hub asks for consent again before the next sign-in.
